Privacy Policy

Last updated: 30 October 2026

Studio Konten Pribadi ("the app") is a personal tool operated by a single owner. It is not distributed to or used by the public.

Data the app accesses

When the owner signs in with Google, the app requests access to the owner's own YouTube account in order to: upload videos, edit the metadata and schedule of the owner's videos, and read the owner's channel and video information. The app uses these Google scopes: youtube.upload, youtube.readonly and youtube.force-ssl.

How data is used and stored

Data obtained through Google APIs is used only to perform the actions above for the owner's own channels. Sign-in tokens are stored only in files on the owner's own computer. No data is stored on any server operated by the app, and nothing is sold, shared with, or transferred to third parties.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer also removes the app's access.
